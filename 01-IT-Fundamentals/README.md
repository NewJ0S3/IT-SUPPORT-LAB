# 01 – IT Fundamentals

## Overview

This section covers the fundamental concepts of Information Technology, focusing on computer hardware, software, operating systems and basic troubleshooting.

## Learning Objectives

- Understand the main components of a computer.
- Identify different hardware components and their functions.
- Understand operating systems and their basic functionalities.
- Learn basic system diagnostic tools.
- Develop technical documentation skills.

## Topics

| Topic | Description |
|---|---|
| Computer Hardware | CPU, RAM, GPU, storage and peripherals. |
| Operating Systems | OS fundamentals and system architecture. |
| Software | Applications, drivers and system utilities. |
| Troubleshooting | Basic diagnostic and problem-solving techniques. |
